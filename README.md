# نظام إدارة ومزامنة قاعدة بيانات موظفي طاقة غاز | TAQA Gas HR System

نظام ويب سحابي عصري وسريع لإدارة قاعدة بيانات الموظفين والعقود لشركة **طاقة غاز (TAQA Gas)** مربوط بقاعدة بيانات سحابية فائقة السرعة (**Supabase PostgreSQL**) وجاهز للنشر المباشر على منصة **Vercel**.

---

## 🌟 المميزات الرئيسية للنظام

1. **مزامنة شيتات الإكسيل بذكاء (Excel Import & Sync)**:
   - دعم كامل لملفات الإكسيل (`.xlsx`, `.xls`, `.csv`).
   - التعرف التلقائي والمرن على أكثر من 44 عموداً حتى مع اختلاف التنسيقات أو المسافات.
   - التحقق المسبق من صحة البيانات وعرض عدد السجلات الصالحة والتنبيهات قبل الحفظ.
   - خيارين للمزامنة:
     - **تحديث وإضافة (Upsert)**: تحديث بيانات الموظف الموجود بناءً على كود الموظف (`ID`) وإضافة الموظفين الجدد بدون تكرار.
     - **استبدال كامل (Full Overwrite)**: تنظيف قاعدة البيانات واستبدالها بالكامل ببيانات الشيت المرفوع.
   - شريط تقدم فوري يوضح نسبة رفع البيانات دفعة تلو الأخرى.

2. **التحكم الكامل في السجلات (Full CRUD)**:
   - **عرض وتصفح متجاوب**: جدول بيانات متقدم مع تقسيم الصفحات (Pagination) وسرعة استجابة فائقة.
   - **تعديل السجلات**: إمكانية تعديل أي سجل في نافذة منسقة تحفظ التعديلات في السحابة فوراً.
   - **حذف السجلات**: حذف موظف مع نافذة تأكيد أمان لمنع الحذف بالخطأ.
   - **إضافة يدوية**: زر لإضافة موظف جديد بجميع بياناته مباشرة من الواجهة.

3. **بحث وفلاتر متقدمة (Advanced Search & Filters)**:
   - بحث فوري لحظي (Live Search) بالاسم باللغتين، كود الموظف، الرقم القومي، الموبايل، والإيميل.
   - فلاتر منسدلة حسب الشركة، الإدارة، الحالة (Active/Resigned)، والنوع (Male/Female).
   - إمكانية ترتيب الأعمدة بالنقر على رأس العمود (Sorting).

4. **تصدير إكسيل بنقرة زر (Export to Excel)**:
   - تحميل قاعدة البيانات بالكامل أو النتائج المفلترة كملف إكسيل (`.xlsx`) منسق وجاهز.

5. **إحصائيات سريعة (Dashboard Stats)**:
   - إجمالي عدد الموظفين، الموظفون على رأس العمل، عدد الشركات، وعدد الإدارات.

## 🚀 كيفية تشغيل المشروع محلياً

### الطريقة الأولى (الأسهل والأسرع):
افتح مجلد المشروع وانقر نقراً مزدوجاً على ملف:
```text
index.html
```
سيفتح معك مباشرة في متصفحك (Chrome, Edge, Firefox)!

### الطريقة الثانية (عبر سيرفر محلي):
في موجه الأوامر (Terminal) داخل مجلد المشروع:
```bash
python -m http.server 8080
```
ثم افتح الرابط: `http://localhost:8080`

## 🌐 كيفية رفع التطبيق على Vercel (خلال دقيقة واحدة)

### الطريقة الأولى: عبر GitHub (موصى بها)
1. قم بإنشاء مستودع جديد على GitHub (New Repository).
2. ارفع ملفات هذا المجلد عليه.
3. ادخل على حسابك في [Vercel](https://vercel.com) واضغط **"Add New Project"**.
4. اختر المستودع الخاص بك واضغط **Deploy**.
5. سيعطيك Vercel فوراً رابطاً عالمياً سريعاً جداً (مثال: `https://taqa-gas-hr.vercel.app`) يمكنك فتحه من أي جهاز أو موبايل ومشاركته مع فريق العمل!

### الطريقة الثانية: عبر Vercel CLI
في موجه الأوامر:
```bash
npx vercel
```
واتبع الخطوات البسيطة على الشاشة.

## 🔒 الأمان وقاعدة البيانات
- قاعدة البيانات مستضافة على **Supabase (PostgreSQL)**.

- مفاتيح الاتصال مهيأة في ملف `js/config.js`.
